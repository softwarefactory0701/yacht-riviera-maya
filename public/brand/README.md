# Yacht Riviera Maya — recursos de marca

Colocar aquí las variantes definitivas proporcionadas por el cliente, sin alterar sus proporciones:

- `yacht-rm-logo-light.svg` — logotipo horizontal blanco/azul para superficies navy.
- `yacht-rm-mark.svg` — isotipo para espacios compactos.
- `yacht-rm-logo-dark.svg` — variante para fondos claros, si existe en el manual de marca.

El App Shell conserva temporalmente el wordmark tipográfico existente hasta recibir un archivo oficial. No se ha recreado ni inventado un logotipo mediante CSS.
